JAVA语言-面向对象过程
继承中变量私有化的核心知识点：
1. 核心目的：实现封装，保护数据安全，防止外部和子类随意篡改。
2. 访问限制：私有变量（private）子类不可直接访问，必须通过父类提供的公共方法（Getter/Setter）间接操作。
3. 设计原则：隐藏内部实现细节，降低代码耦合度，父类保留对数据的控制权（可在方法中加校验逻辑）。
4. 一句话总结：藏数据，露行为。父类只向子类暴露必要的方法，不暴露具体的属性状态。

Java-子类继承
1.final，static修饰的方法子类不能继承，可以调用。
2.private修饰的方法子类不能继承也不能调用 


在面向对象编程（如 Java、C++、C#）中，子类不能拥有比父类更严格的访问权限。核心原则是：子类重写方法时，访问权限只能相同或更大。


多态的实现条件（三个必须）
1. 继承：存在父类和子类关系
2. 重写：子类重写父类的方法
3. 向上转型：父类引用指向子类对象
